# 🎲 Vitopoly Rush 2.0 - Official Rulebook

![Vitopoly Rush 2.0 Banner](https://img.shields.io/badge/Status-Active-success) ![Version](https://img.shields.io/badge/Version-2.0-blue)

Welcome to the **Vitopoly Rush 2.0** Official Rulebook repository! This project hosts a stunning, high-stakes, cyberpunk-themed rulebook for a campus-wide real-estate conquest event.

## 🌟 Features
* **Modern Cyberpunk Aesthetic**: Uses sleek neon colors, holographic gradients, and a starfield parallax background for an immersive reading experience.
* **Separation of Concerns**: Neatly organized into separate HTML, CSS, and JavaScript files for maintainability.
* **Interactive Elements**:
  * Panning gradients on section titles.
  * Scanline animations and hovering, glowing property cards.
  * Working tab navigation for properties.
  * Functional random generators for Dares, Violations, Extra Class abilities, and Treasure Chests directly inside the rulebook.

## 📂 Project Structure
* `index.html`: The core structure and content of the rulebook.
* `style.css`: All styling, animations, and "wow factor" visual effects.
* `script.js`: Interactive functionality, parallax effects, and the randomized event generation logic.

## 🛠️ Usage
To run the project locally, you only need a web browser! 
1. Clone the repository:
   ```bash
   git clone https://github.com/sudeep-makindar/vitopoly.git
   ```
2. Open the directory and double-click the `index.html` file to launch the rulebook.
